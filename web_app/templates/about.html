Project Overview: STACPRED v2.0.0

STACPRED (Stacked Affinity Prediction) is a computational tool for high-confidence prediction of binding affinity (kCal/mol) of small molecules targeting the allosteric Sirtuin-1 (SIRT1) activation site.

Core Methodology

The ensemble employs Stacked Generalization (8 base models: 4 XGBoost + 4 MLP) fused by a meta-learner (RidgeCV). This multi-layer consensus design reduces model bias and enhances robustness.

Final Stack Accuracy: R² = 0.9154   |   RMSE = 0.3090

Technical Stack

  • Python (Scikit-learn, XGBoost, TensorFlow/Keras)
  • RDKit / OpenBabel feature generation
  • Flask REST API backend
  • Tailwind CSS frontend (Glassmorphism UI)
